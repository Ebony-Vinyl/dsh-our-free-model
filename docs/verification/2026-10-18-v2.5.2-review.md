# v2.5.2 本地复审与发布验收

## 本次复审发现并修复

### [P2] 同步根依赖锁文件

新增的 `package-lock.json` 仍记录 2.0.0，且缺少 `package.json` 已声明的 `jose@6.1.3` 和 `undici@8.11.2`。`npm ci --ignore-scripts --dry-run` 实际返回 EUSAGE，干净检出无法按锁文件安装。已重新生成根锁文件，并同步三个 npm 包及 Rust/Tauri 的 2.5.2 版本号。独立前端和桌面锁文件保留原依赖版本与平台元数据。

### [P2] 成功回滚后恢复只读文件权限

`src/updater.js` 的权限重试在成功复制后未恢复先前权限。原有回归只验证旧字节和失败重试，遗漏成功路径。新增原权限断言后在 Windows 复现失败；补充成功后的 `chmodSync` 后通过。复制失败时仍恢复原权限、保留现有文件并报告回滚失败。

### [P2] 将 LAN 回归接入默认测试

独立服务新增 LAN 中继及 523 行回归脚本，但默认测试入口没有调用它。已增加 `standalone-lan` 套件，纳入 contributor 和完整测试，防止默认 CI 漏验新增网络入口。
