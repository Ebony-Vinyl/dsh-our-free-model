## 已核验的性能证据

基线固定为 `4530975`，旧模块树只从 Git 临时提取供测试，测试后清理，不进入当前源码发布内容。

- 十二种十万行工具输出：除纠正未安装 RTK CLI 的误导提示外，输出比较通过。本机所记录的中位耗时下降约 9%–42%，见 `docs/plans/compression-benchmark.jsonl`。
- 本地应答：五类代表性请求输出比较通过，交替顺序测量本轮约下降 22%。
- Chat 工具适配：40 个声明、100 个历史调用，12 轮交替顺序，每轮 1000 请求；本轮中位耗时约从 152.73ms 降至 119.93ms，下降 21.48%，见 `docs/plans/toolshape-benchmark.jsonl`。

以上是具体合成负载结果，不证明线上端到端延迟普遍改善。重新编写的提示和工具描述有意与旧文案不同，不能宣称逐字输出等价。
