# Our Free Model 2.4.0

## 本次更新

- 免费车道按上游 2026-10-14 起生效的 **OpenCode v2 客户端**重做指纹。四类特征一起变，缺一即
  `403 FreeTierError`：
  - User-Agent 换成 `opencode/latest/2.0.26/cli`（旧 `opencode/1.18.x` 被上游按名字拒掉）；
  - 会话头补齐 `x-session-affinity` / `x-session-id`，与 `x-opencode-session` /
    `x-opencode-session-id` 四头同值；**不再**发 v1 专用的 `x-opencode-request`；
  - 工具闸门改为 `read` 与 `shell` 两个名字，且 description 与参数 schema 必须与官方客户端
    逐字一致——v1 时代「桩工具 + 占位 property」的做法已失效；
  - `tool_choice: 'none'` 一律不下发（上游见到即 403），续写回合改由指令正文压制工具调用。
- 调用方的工具**原样保留**（含 `Read`/`Bash` 这类大小写变体）。若正好用了 `read`/`shell` 而定义
  不同，该工具改名成 `<name>_client`，并同步改写历史里的同名调用与 `tool_choice`，响应侧再还原
  成调用方的名字——插件自己的车道与 vendored 渠道包两侧行为一致。
- 新增 `scripts/opencode-parity-test.mjs`：逐项断言两侧指纹（闸门名、定义逐字、UA、头集、别名、
  历史改写、`tool_choice`、档位收敛）不再漂移，已接入 `npm run test:contributor`。
- 新增「推荐项目」页：两张卡片分别指向 EAC-Desktop 与 EAC-Pack，Star / Fork / 最近提交数实时
  取自 GitHub；取不到就整块不显示，绝不用占位数字。该页同时加入标签持久化列表，刷新后仍停在
  原页。
- 聚合渠道注册表移除 OpenCode 免密池一行：它要求每请求的会话 id、v2 客户端 UA 与一组官方工具
  声明，聚合车道的通用传输没有地方承载这些，硬列进来只会是一个点不通的选择器行；这 10 个模型
  由免费车道原生提供。注册表因此为 **75 家**。
- 插件、独立本地服务和 Windows 桌面壳统一升级到 2.4.0。

## 升级与重启

### DSH 插件

在设置 → 插件升级中检查并安装 2.4.0。升级前结束正在生成的请求；安装完成后完全退出 DSH desktop
（包括托盘）并重新启动，再确认版本号和免费模型目录。

### 独立本地服务

先停止旧服务并备份程序目录和数据目录，再替换程序文件。使用原来的数据目录启动新版，通过启动时
输出的管理链接登录，确认页面显示 2.4.0。不要同时运行两个实例共用一个数据目录。

### Windows 桌面应用

从托盘菜单选择“退出”后安装新版完整安装包（`Our.Free.Model_2.4.0_x64-setup.exe`），再重新打开
应用。不要只复制可执行文件；安装包包含独立服务和运行时资源。

### macOS 桌面应用

本次未构建 macOS 安装包（构建机为 Windows）。macOS ARM64 用户请继续使用 v2.3.0 的 DMG，或
直接使用独立本地服务 CLI；本版的免费车道改动同样适用于独立服务。

## 数据与回退

升级保留现有配置、账号和统计数据。免费车道继续复用本地会话映射；会话 id 的形状不变，只是上游
新增了「计数器必须很小」的约束，而铸造器每毫秒归零，天然满足。

回退方式：插件使用升级前的完整插件备份，独立服务恢复旧程序目录，桌面端恢复旧版完整安装包。
不要删除数据目录、锁文件或账号凭据来处理升级失败。
