# Our Free Model 2.5.3

紧急修复 2.5.2 新增的 EAC 无有效输出等待限制。

## 修复

- 移除 EAC 连续 60 秒没有正文、思考或工具增量就终止请求的规则，不再由该规则产生 `NO_PROGRESS`。
- 排队、静默思考、仅有心跳或用量帧，以及正文输出后的静默间隔，均不会再触发这项截止。
- 旧配置中的 `progressTimeoutMs` 不再生效。用户取消仍会关闭上游请求；既有传输断线检测和恢复总时限保持原行为。
- 不修改 OpenCode 请求头、会话编码、工具声明、模型目录或供应商准入逻辑。
- 修复本地开发目录安装时，自升级将 `packages/desktop/src-tauri/target` 编译缓存也复制进回滚目录而占满系统盘的问题。`packages` 下的独立产品源码与缓存不参与插件备份和清理；原文件保留。

## 安装与更新

DSH 插件使用本 Release 的 `dsh-our-free-model-2.5.3.tgz`。由包管理器托管的安装请更新 profile 中的 tarball 路径，并通过宿主重新解析依赖；同名 npm 包不由本仓库发布。

Windows 桌面端请完全退出托盘中的旧程序，再运行 `Our.Free.Model_2.5.3_x64-setup.exe`。配置、账号和统计数据保留。安装包未经 Authenticode 签名。

校验文件和发布验收记录随产物提供。

## 可用性

此次修复不代表匿名 OpenCode 的 `403 / FreeTierError / LANE_LOCKED` 已恢复，也不会把真实被拒绝的模型标记为可用。供应商网络、授权和配额仍会影响推理结果。
