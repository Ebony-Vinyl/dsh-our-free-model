# v2.8.0 插件发布

本次只发布 DSH 插件，桌面安装包和独立产品版本保持原状。两个主线改动都在免费道与自带引擎的
"跟上上游"这一层：匿名免费道的请求整形整体换成参考网关 opencode2api v1.4.6 的逐文件 JS 移植，
自带 Magpie 引擎从 10-23 的 c551a22 跟进到 10-31 的 6a900e0d——并且从此跟进是一条命令。

## 匿名免费道：整形层移植 opencode2api v1.4.6

- **全部客户工具改名上线**：每个调用方工具改名成不透明的 `clint_<sha256[:12]>` 线名
  （`tool_choice`、历史 tool_calls / tool_use / function_call、Responses `input` 调用行同步
  改名，响应侧折叠还原），外来客户端的工具词汇一概不再上线——2026-10-30 实测
  `ReportFindings`/`ScheduleWakeup` 同现即 429，改名是那个两别名表的推广形式。
- **官方 13 工具集全量声明**：定义逐字取自官方 2.1 CLI 的捕获文件（chat 线带
  `strict: false`，Windows 主机 shell 描述写 powershell）；已带逐字官方定义的声明视为
  官方声明，重复整形是幂等的。
- **官方 CLI 系统提示全量注入**：base prompt + `<env>` + 内置 skills，逐线前插，调用方的
  块对象与 `cache_control` 原样保留；已带标记的请求体跳过。
- **每会话一个稳定的 40-hex `x-opencode-project`**：配额按项目 × 出口记账，默认由
  会话派生，重试与续写不更换项目；调用方给的字面 `global` 或 40-hex commit 直通。
- **端点跟随 2.1 客户端的族路径**：`/inference/openai/v1/…`、
  `/inference/anthropic/v1/messages?beta=true`；Messages 线补 `anthropic-beta` 头。
- **会话铸造走慢钟**：今日 UTC 零点减去 ≤30 天的哈希偏移（进程盐），会话日期永远落在
  上游接受窗口内；持久化的旧 id 一旦日期出窗即重铸，一个会话仍钉死一个会话。
- Chat 体补上官方客户端的两个常量字段：流式 `stream_options.include_usage: true`、
  无上限时 `max_completion_tokens: 32000`；`tool_choice: 'none'` 的兜底清除保留。
- 移植是纯函数目录 `src/o2a/`（文件对照表与七条有意偏差见其 `SYNC.md`），发布形态仍是
  单文件 bundle，80 文件预算不变。

## 自带 Magpie 引擎跟进到 6a900e0d（2026-10-31）

- 引擎钉住上游 6a900e0d 重新构建，构建旗标改为上游 release 同款 `-s -w`：二进制
  68.6 MB → 64.8 MB，gzip 载荷 45.3 MB → 27.2 MB，**77 文件**重回旧版升级器的 80 文件上限
  之内（不裁剪则需要 81 个，正是真实 1.3.1/2.5.9 拒收的数）。
- 新增 `npm run update:magpie`（`scripts/update-magpie-engine.mjs`）：解析目标 revision、
  移动唯一钉子、重建、刷新分片与 bundle，跑完六套契约套件才算完成；失败自动把钉子与
  引擎状态回滚到运行前。
- 引擎 UI 一处窄面板修复：设置列表里 "Long conversations · Compact at"（#876）的 76px
  数字输入在 320px 窄板下被裁掉一半，补上与上游 agent prefs 同款的 shrink-and-wrap。
- 插件/原生套件的预设断言解冻为当前上游（59 个内置、14 个带区、64 区），revision 断言
  改读 `engine.json`，下次引擎更新不再需要改测试。

## 协付渠道模型卡按 NVIDIA Build 页面重核

- DeepSeek V4.1 Flash / GLM 5.3 Flash / 新增 Mistral Large 4 1T A52B 的窗口、视觉与思考
  档位按 NVIDIA Build 各自的模型页与 chat schema 重核：档位枚举取平台校验集
  （`none|minimal|low|medium|high|xhigh|max`），Mistral 只有 Off/High 两档（High 默认）。
- 免费道两个 id 的卡片改按高速通道的 highspeed 名展示（`deepseek-v4.1-flash-highspeed
  1017` / `glm-5.3-flash-highspeed`），catalog id 不动，路由不受影响。

## 测试与守卫

- `npm test` 新增 `legacy-payload` 套件（`build-legacy-payload.mjs --check`）：发布
  bundle（token-saver / o2a / core）与引擎分片必须和源码一致，改了 `src/o2a/` 忘了重打包
  会在测试里当场红，而不是静默测旧代码。
- 指纹/线形/别名/对齐四套件全部重写成 o2a 移植的行为断言；独立端 mock 跟随族路径与
  2.1.1 UA。

## 安装与验证

发布前通过了完整 release 套件（110/110）：生产签名、原版 1.3.1 与 2.5.9 旧版升级回归、
生成产物一致性检查、目录记录与字节一致性检查。发布 tarball 从固定提交的 LF 字节构建，
运行时文件逐字节匹配正式签名清单，解包后入口加载通过。发布后以已安装用户身份完成默认
更新源的取件校验（live-audit），并整树刷新 CDN。

免费道线形的真机放行验证受本机出口配额限制：权威对照（本地构建运行的 opencode2api
v1.4.6 参考网关）在同一出口同一时刻收到完全相同的 `FreeUsageLimitError`，证明该 429 是
出口配额而非移植缺陷；配额重置后可用 `scripts/oc-free-live-test.mjs --live` 一次收口。

自行安装的旧版用户可在插件升级页检查更新；宿主管理的安装请通过原安装方式更新可信
tarball；手工安装使用本次完整插件包，保留原有用户数据目录，不要仅替换入口文件。测试仅
访问本地服务，不代表所有网络环境或真实模型上游均已验证。

## 回退

升级器继续执行原有签名、文件大小、SHA-256、备份与回滚校验。手工回退使用上一版可信
