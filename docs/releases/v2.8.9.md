# 2.8.9：安全修复与渠道可用性修复

在 2.8.6 核心重写之上的一版修复，不回退任何 2.8.6 的行为。升级不修改现有账号、
配置与归档。

## 安全

- **反馈页的验证地址改为只接受 https**。`verifyUrl` 来自反馈收集服务，随后直接进入
  页面的 `href` 与 `window.open` —— 未经校验时，一个被攻破或配错的收集端可以让用户
  在持有管理会话的同源里执行脚本。现在只放行 https（本机收集端保留 loopback http），
  其余一律退回 GitHub 官方验证页；验证码仍然照常显示，登录不会因此失败。插件端与
  独立端两处实现同步收紧，并各有回归断言覆盖 `javascript:` / `data:` / `vbscript:` /
  `file:` / 明文 http / 带凭据 / 超长等输入。

## 渠道可用性

- **风控停用的账号立即止损**（#850）。上游以 403 判定"账号存在异常行为/已被限制使用"
  时，逐个换号只会把同批同源账号一起打进风控。现在单独识别这一类、记为不可自愈的
  徽章，并直接告知需要申诉或换平台，而不是让用户等一个不会恢复的状态。
- **额度耗尽补齐两种形态**（#721）。除业务码 `110` 外，`112` 与带 `pricingUrl` 的
  「去购买」引导页同样判定为额度耗尽，死号会被正确标记并换号，不再每轮重复选中。
- **Qoder WASM 的输入缓冲区不再泄漏**（#826）。此前每次调用都漏掉 `__wbindgen_free`
  的配对，泄漏量与参数大小成正比；现在分配、调用、释放成对执行。

## 流与工具调用

- **只关闭工具块、不流式下发增量的上游也能正常产出调用**（#829）。这类适配器过去会
  在 `finish_reason: tool_calls` 下发出零个工具帧，客户端无从执行；现在按同一道闸门
  补出帧，且不会与已下发的增量重复拼接参数。
- **凭据脱敏不再误伤普通文本与工具名**（#877）。此前以 `s` 开头的网关 key 让每个以
  `s` 结尾的单词都被当成 key 前缀，`list_agents` 变成 `list_agent[redacted]`，工具
  调用一律 `unknown tool`。现在单字符残片不再被当作秘密截断，真正的完整密钥（含跨
  分片）仍然照常脱敏。
- **EAC 超时说明停在哪一步**（#433）。空闲死线触发时报告实际到达的帧数与内容帧数，
  用来区分"上游什么都没发"与"只发了心跳"，而不是只给一句 `timeout`。
- **思考循环判定改用字符去重率**（#748）。行数口径把短行密集的正常枚举误判为复读，
  字符口径不会。

## 界面

- **模型卡片显示能力标签**（#869）：长文本、长输出、视觉、可调思考、多档思考、快、
  EAC。全部由条目自身字段派生，没有声明的模型不会得到错误标签。
- **美元余额按货币格式化**（#821）。Cline 的 `unit: 'dollars'` 余额不再被 token
  缩写器压成 `1.2K`。
- **表单底部按钮固定在滚动区可见位置**（#724）。

## 独立端

- **管理会话滑动续期**（#557）。持续使用的控制台不再在固定 8 小时整点被踢出，空闲
  会话仍按时过期，Cookie 的 `Max-Age` 不重写。
- **Magpie 引擎缺失时说清下一步**（#872）。二进制无法还原时报告是哪一种故障，并给
  出重装或重建的具体命令。

## npm 渠道

- 新增 `scripts/publish-scoped.mjs`：scoped 产物必须由脚本生成，三处「包自称」的
  注册字面量（`client.js` 的工厂 id、`cordis.patch.yml` 的挂载行、`src/updater.js`
  的 pnpm 所有权键）跟着改名走，漏一处就会让桌面端启动时报
  `1 entry did not activate`（#725 / #835）。`--check` 已接进测试套件。
