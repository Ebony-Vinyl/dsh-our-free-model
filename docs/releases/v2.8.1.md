# 2.8.1 — OFM 扩展市场、免费车道额度断路器与免费页重做

发布日期：2026-11-07。上游背景：OpenCode 在 10 月底收紧免费额度与客户端校验（#708/#767 实测：配额按**出口 IP** 计，`Retry-After` 以小时计；官方 2.2.3 客户端出站携带 `traceparent`/`b3`）。本轮回答两件事：怎么不自己把额度烧光，以及渠道怎么交给社区。

## 免费车道（OpenCode 匿名）

- **额度断路器**：一次真实 429 → 车道开窗（`Retry-After`，缺省 6 小时），窗口内新回合本地拒绝，不再向上游送任何请求；`FreeTierError` → 锁道；出口变更自动清窗一次。设置页横幅显示倒计时与「换出口后重试一次」。
- **手动测试全部保留**：清单刷新、单模型「检测一次」、模型卡测速。自动探测依旧禁用；可用性从真实回合**被动学习**（available / throttled / region-blocked）。
- **出口代理**：车道级 `freeLane.proxyUrl`（http/https/socks5），亦认 `HTTP_PROXY`/`HTTPS_PROXY`/`NO_PROXY`；Node 传输路径以 in-process 隧道直连代理；「测试出口」打第三方回显，不花配额。这就是 #708 里「zen 配额绕过」的合法等价物——换出口，绝不自动轮换。
- **指纹对齐官方 2.2.3**（#708 抓包）：UA `opencode/latest/2.2.3/cli`、`traceparent` + `b3`（每请求新生的 W3C 追溯对）、通配 `accept`。
- **opencode2api v1.4.7 移植**：官方工具名绑定（`Bash→shell`、`Read→read` 等）、幽灵工具调用与孤儿结果清理（可服务的官方别名先改写再谈丢弃）、流式工具名缓冲、标题请求免整形（不再把 13 件官方工具发给一条标题生成）。
- **项目稳定**：`x-opencode-project` 默认按会话派生（PR #757 思路），一次会话一个配额桶。
- **清单刷新**（2026-11 live）：`beam-free`、`flint-40b-free`、`pulse-alpha-free`、`crouton-alpha-free`、`nemotron-3.5-super-vl-free`、`nemotron-3.5-lightning-free` 等入库；`space-bunny-free`、`mimo-v2.5-free`、`union-alpha`、`muse-spark-*` 等退役 id 移除；beam/crouton/pulse 标记地区敏感。Bun 仅对 POST 推理强制——无 Bun 也能刷清单。

## Kilo

- 默认 base 迁到官方文档的 `https://ai-gateway.kilo.ai/api/v1`（旧 host 仍可覆写）；清单 ETag 协商缓存；补 Kilo 官方归因头。
- 免费池快照刷新为 2026-11-07 的 11 个 `isFree` id（nemotron-3.5 家族、crouton、glyph-cluster、dots-3、north-mini-code、openrouter/free 等）。

## OFM 扩展（新）

- 新仓库 **Ebony-Vinyl/ofm-extensions**：`registry.json` + `registry.sig`（Ed25519），PR 投稿 + CI 校验 + 人工审核。
- 客户端（`src/extensions.js`）：镜像拉取（raw/jsDelivr/gh-proxy）→ 签名校验（公钥 pin）→ 大小/SHA-256 → 静态扫描（`node:*`/`require`/`process`/`eval`/动态 import/压缩产物全拒）→ 安装到数据目录（版本化 + 回滚 + 审计日志）→ Worker + `vm.SourceTextModule` 沙箱运行（唯一 import 是 `ofm:sdk`；fetch/密钥/存储全走受控桥；hook 超时即熔断重启）。
- 渠道插件：`listModels` + `prepareChat` → 宿主共享流式核（与聚合车道同一套 SSE/JSON 折叠）；`replaces` 可接管内置车道（id 原样、内置行让位）。增强插件：`onRequest`/`onModels`/`onUsage`，默认安装即停用，fail-open。
- 设置页新增「扩展」页：发现 / 已安装 / 安全。独立版同步接入。

## 界面

- 免费模型页**保持既有设计不变**（应用户要求回退全部改版）；新增的「扩展」页签是本轮唯一的界面新增：发现 / 已安装 / 安全三页签，安装/更新/启停/配置/卸载全在页内完成。
- 扩展渠道的模型出现在既有免费页清单与统计中（`channel: 'extension'`）。
- 额度窗口以回合失败文案与「检测一次」结果呈现，不再有横幅；出口代理经环境变量或设置 API 配置。
