# 2.8.6 候选：核心实现替换

此文件描述待验收候选，不表示版本已经发布。

- 重写免费通道请求适配、工具输出压缩、本地应答与失败分类，保持现有协议接口和配置键。
- 删除当前树中的两份逐字复制请求资产，改用 OFM 编写的上下文与工具描述。
- 从官方资料和明确许可的模型目录重建供应商记录；历史兼容记录保留旧 ID、端点、协议与预算，注明退役、未确认和可能由上游回落的限制，不自动切换模型、价格档位或协议。
- 修正压缩差异提示，不再要求使用 OFM 未安装的 RTK CLI。
- 独立端连接窗口展示渠道说明，配置旧模型 ID 前可查看退役和上游回落限制。
- 十二类固定大输入的压缩基准、本地应答及 Chat 工具适配基准有改善；结果只适用于记录的合成负载，见验证报告。

升级不修改现有账号、配置和归档。部分模型已被上游退役或调整，保留旧 ID 不代表恢复其服务；Kimi 旧 ID 可能由上游映射到不同模型。详见 [历史配置兼容说明](../provider-compatibility.md)。

社区桥 RTK 替换在 ofm-extensions PR #5 单独交付，主插件升级不会自动迁移社区桥。

来源与许可证记录保留；本次已参考原源码，不宣称 clean-room 或仅凭改写消除许可义务。正式发布仍以真实调用、候选签名及发布产物验收为准。
