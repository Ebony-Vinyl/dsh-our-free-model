# Our Free Model 2.5.8

## 插件更新

本版本发布 DSH 插件，包含自 2.5.7 后已合入主线的修正：

- 更新失败重试：Windows 备份目录重命名遇到临时占用时重试；再次更新可复用已校验的暂存文件，减少重复下载。
- Qoder 思考档位按强度从低到高排序，保留原始档位 ID 和默认值，未知档位稳定排列在末尾。
- 本地 OpenAI 网关接收 Chat 历史时保留 `reasoning_content` / `reasoning`，包括单个空格占位，修复思考模式工具轮次丢失推理内容的问题；Responses 加密推理项仍按原有约定丢弃。
- Chat 转发保留客户端显式提供的助手 `reasoning_content` 字符串及空字符串，支持工具调用后的后续请求。
- 重新生成插件渠道包与独立渠道产物，使已合并的网关源码修复进入实际运行文件。
- 移除 WorkBuddy 国内版和国际版渠道入口，保留历史账号、凭据及用户数据。
- EAC DeepSeek Flash 显示名称和卡片标签增加 `1017` 标识；更新交流群 4 的群号和二维码。

独立服务和桌面壳版本保持不变，本次不发布新的 Windows 桌面安装包。标签触发的 macOS 社区构建由现有 CI 单独处理。

## 安装

插件包为 `dsh-our-free-model-2.5.8.tgz`。托管安装请更新 profile 中的可信 tarball 路径，再由宿主重新解析依赖；自行安装按现有插件更新流程操作。

无需迁移用户配置、账号或统计数据。历史 WorkBuddy 账号与凭据保留，但对应渠道不再提供调用入口。

## 验证边界

更新重试、渠道挂载、网关推理回传与转发使用本地替身验证。未验证真实上游账号调用或 Windows 实机文件占用场景；测试结果不代表上游客户端、地区或配额限制已解除。

## 回退

回退到 `2.5.7` 的可信插件 tarball，并按宿主安装流程重新解析。保留用户配置、账号及统计数据。
