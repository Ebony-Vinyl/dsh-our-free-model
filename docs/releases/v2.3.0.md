# Our Free Model 2.3.0

## 本次更新

- 免费模型车道迁移到新的 `/inference/v1` 请求路径，补齐上游要求的会话标识、工具指纹和客户端归属处理。
- 免费车道会持久化会话映射，服务重启后继续使用原会话；上游 `FreeTierError` 会被识别为线路锁定，不再误导用户重复登录或清空模型目录。
- 插件升级页独立为导航入口，展示当前版本、磁盘版本、升级进度和失败原因；原设置页保留设置功能，不再重复渲染升级面板。
- 插件、独立本地服务和 Windows 桌面壳统一升级到 2.3.0。

## 升级与重启

### DSH 插件

在设置 → 插件升级中检查并安装 2.3.0。升级前结束正在生成的请求；安装完成后完全退出 DSH desktop（包括托盘）并重新启动，再确认版本号和免费模型目录。

### 独立本地服务

先停止旧服务并备份程序目录和数据目录，再替换程序文件。使用原来的数据目录启动新版，通过启动时输出的管理链接登录，确认页面显示 2.3.0。不要同时运行两个实例共用一个数据目录。

### Windows 桌面应用

从托盘菜单选择“退出”后安装新版完整安装包，再重新打开应用。不要只复制可执行文件；安装包包含独立服务和运行时资源。

## 数据与回退

升级保留现有配置、账号和统计数据。免费车道会迁移并复用本地会话映射；若服务无法启动，先停止当前实例，再恢复旧版完整程序和原数据目录备份。

回退方式：插件使用升级前的完整插件备份，独立服务恢复旧程序目录，桌面端恢复旧版完整安装包。不要删除数据目录、锁文件或账号凭据来处理升级失败。
