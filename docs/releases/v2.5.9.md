# Our Free Model 2.5.9

## 插件更新

本版本发布 DSH 插件，包含自 2.5.8 后已合入主线的清理与修正：

- 移除不再提供的账号渠道及其登录、OAuth、模型、积分、请求签名和专用 RPC，实现与页面入口一并清理；保留其他 10 个账号渠道、匿名免费通道和 EAC。
- 提取其他渠道仍使用的浏览器打开器与限流工具，移除闲置依赖；保留原有开源版权与作者归属。
- 重新生成插件渠道包和独立服务渠道资源，桌面端打包仅收录资源清单中的文件，并在构建时删除过期前端资源。
- 共享存储和备份改用中性命名，旧版偏好、锁定、统计和有效备份保持可读取、可导入。
- 同步中英文及独立版 README 的渠道说明，更新交流群 5 的二维码和群号 `1128964440`。

独立服务和桌面壳版本保持不变，本次不发布新的 Windows 桌面安装包。标签触发的 macOS 社区构建由现有 CI 单独处理。

## 安装

插件包为 `dsh-our-free-model-2.5.9.tgz`。托管安装请更新 profile 中的可信 tarball 路径，再由宿主重新解析依赖；自行安装可通过插件升级页面更新。

## 验证边界

发布前检查插件渠道挂载、历史存储与备份兼容、生成资源一致性，以及签名清单与安装包字节完整性。真实上游账号调用、Windows/macOS 安装器安装不在本次验收范围内；本版本不承诺解除上游客户端、地区或配额限制。

## 回退

恢复 `2.5.8` 的可信插件 tarball，并按宿主安装流程重新解析。保留用户配置、账号及统计数据。
