# Our Free Model 2.5.6

## 插件更新

本版本发布 DSH 插件，包含已合入 main 的 PR #492：

- 在免费模型和 EAC 模型页面上方统一展示北辰 API 赞助卡片。
- 缩小卡片尺寸，精简间距、图标和文字布局。
- 品牌文案统一为北辰 API 与 OFM，优惠说明调整为“邀请可获百分之十的返现”。
- 移除“来自赞助商的广告”导航及详情路由，保留卡片和“立即查看”链接。
- 修复部分 macOS 临时目录路径下热重载依赖未刷新导致的旧模块继续运行问题。

独立本地服务和桌面壳不随本版本更新。

## 安装

插件包为 `dsh-our-free-model-2.5.6.tgz`。托管安装请更新 profile 中的可信 tarball 路径，再由宿主重新解析依赖。

## 回退

回退到 `2.5.5` 的插件 tarball，并按宿主的插件安装流程重新解析即可；用户配置、账号和统计数据无需迁移。
