# Our Free Model 2.2.0

## 本次更新

- EAC 服务已迁移到新的服务器，更新并重启后会使用新服务。
- 完善 GitHub 授权与 Star 状态确认流程，保留原有账号管理入口。
- 提供 DSH 插件、独立本地服务及 Windows 桌面应用，版本统一为 2.2.0。
- 桌面应用内置运行环境，改善启动、窗口恢复和退出时的服务清理。

## 升级与重启

### DSH 插件

升级前结束正在生成的请求，并备份插件目录及用户数据。通过插件更新入口检查更新、安装 2.2.0，随后完全退出 DSH desktop（包括托盘）并重新启动。打开 Our Free Model 确认版本；如 EAC 提示需要授权，请重新完成 GitHub 登录及 Star 状态确认。

### 独立本地服务

先停止旧服务，备份原程序目录和数据目录，再将新版解压到新的目录。使用原来的数据目录启动，避免同时运行两份服务。打开启动时输出的管理链接，确认版本为 2.2.0。Windows 便携包使用附带启动脚本，无需额外安装 Node。

### Windows 桌面应用

先从托盘菜单选择“退出”，再安装新版完整安装包并重新打开。仅关闭面板会隐藏到托盘，不等于停止服务。不要单独复制 EXE 替代完整安装包。

## 数据与授权

升级保留现有配置和用户数据。服务器迁移后，旧 EAC 授权可能需要重新登录。若无法完成授权，请从应用内重新发起登录，不要继续使用之前保存的登录页面。

## 回退

回退前停止所有当前服务，并再次备份数据。

- DSH 插件：使用升级前保留的完整插件备份恢复，然后完全退出并重启 DSH。
- 独立服务：恢复旧程序目录，使用备份的数据目录启动。
- 桌面应用：退出托盘后恢复旧版完整安装包；如旧版无法读取新数据，请使用升级前的数据备份。

回退到旧程序不保证旧服务器仍可使用；旧 EAC 服务不可用时，应升级回 2.2.0。不要通过删除账号数据、未知锁文件或强杀无关进程解决升级问题。
