# v2.7.4 插件发布

本次只发布 DSH 插件，桌面安装包和独立产品版本保持原状。这是 2026-10-31 全量 issue 审计的发版：
合并 19 个社区修复 PR 与 8 项本地修复，全部先在本地验证再合入。

## 转发与流式协议

- 流式 `tool_calls` 帧只在首帧携带 id/name，index 从 0 起连续编号，不再发出缺 function 的裸 index 帧（#621、#452）。
- Responses 流每帧补上必填的 sequence_number（#548）。
- 上游 5xx 空响应体时明确说明是哪一层失败，并提示请求带了图片（#549）。
- 工具参数语法非法与长度截断分离判定（#474）。
- keepalive 注释帧不再无限续命空闲死线，空闲时钟只由真数据上弦（#460）。
- `ChannelNetworkError` 补上 code，瞬时网络失败可正常重试（#587）。

## 会话、聚合与模型目录

- 并发会话隔离，无 sessionId 的回合不再共享 global 会话（#532）。
- combo 链上的静默候选不再阻塞整条链（#630）。
- 聚合渠道补上 modelsUrl，修复 "declares no model listing" 误报（#682）；16 个 provider 补上已验证的 modelsUrl（#538）。
- `-vl` 段视为视觉标记，家族规则不再把视觉变体标成纯文本（#458）。
- Gemini 工具 schema 剔除空串 enum 成员，避免上游 400（#251）。

## 账号渠道与管理端

- trae 用量帧读取缓存命中字段，cacheReadTokens 不再恒为 0（#701/#213）。
- 渠道账号「测试」按候选链测试模型并回传耗时，补上 Loomy 探测分支（#681）。
- 渠道模型隐藏后会话选择器刷新（#644）。
- 管理端模型刷新接口返回各来源结果（#670）。
- EAC 登录支持 Windows 系统代理（#620）；浏览器启动改为调用时解析 execFile，离线桩可生效。
- openai-gateway 工具调用帧兼容新旧 DSH 内核（#610）。

## 工作台与客户端

- Windows 保留端口段（winnat/Hyper-V/WSL）跨重启漂移不再导致工作台恒定「启动失败」，占用端口改取新端口并持久化（#688）。
- 工作台展开瞬间不再丢失收起按钮，iframe 内 Esc 也能收起（#700）。
- 公告清理 hook 提前到提前返回之前，修复 React hooks 顺序（#631）。

## 安全与升级

- Windows 上私有文件 0600 承诺经 icacls 实际生效（#456）；权限模块并入 `open-external.js`，发布包保持 80 文件预算。
- `undici` 改为按需加载；缺 undici 时代理路径抛出明确错误而不静默直连，避免代理用户 IP 泄漏。
- pnpm 托管的安装拒绝应用内升级，交还原安装方式维护（#335）。
- 管理边界对第三方文案做排除渠道名脱敏，上游市场新条目不再打破不变量。

## 安装与验证

发布前通过了完整 release 套件：生产签名、原版 1.3.1 与 2.5.9 旧版升级回归 8/8、生成产物一致性检查、
目录记录与字节一致性检查。发布 tarball 从固定提交的 LF 字节构建，80 个运行时文件逐字节匹配正式签名清单，
解包后入口加载通过。发布后以已安装用户身份完成四个默认更新源的取件校验（live-audit），并整树刷新 CDN。

自行安装的旧版用户可在插件升级页检查更新；宿主管理的安装请通过原安装方式更新可信 tarball；
手工安装使用本次完整插件包，保留原有用户数据目录，不要仅替换入口文件。测试仅访问本地服务，
不代表所有网络环境或真实模型上游均已验证。

## 回退

升级器继续执行原有签名、文件大小、SHA-256、备份与回滚校验。手工回退使用上一版可信插件包，
并保留配置、账号及统计数据。
