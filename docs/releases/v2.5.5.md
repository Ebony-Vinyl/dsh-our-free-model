# Our Free Model 2.5.5

## 插件更新

本版本只发布 DSH 插件，基于已合入 `main` 的插件改动：

- 删除赞助说明中的交流群、群号和“复制群号”按钮。
- 关闭 DeepSeek Harness desktop 插件启动时自动弹出的赞助开屏广告。
- 保留赞助页面入口和邀请码功能。

独立本地服务和桌面壳不随本版本更新。

## 安装

插件包为 `dsh-our-free-model-2.5.5.tgz`。托管安装请更新 profile 中的可信 tarball 路径，再由宿主重新解析依赖。

## 回退

回退到 `2.5.4` 的插件 tarball，并按宿主的插件安装流程重新解析即可；用户配置、账号和统计数据无需迁移。
