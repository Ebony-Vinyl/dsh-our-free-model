# Our Free Model 2.5.4

优化新桌面端，优化插件端 UI 和广告。

## 更新内容

- 优化新桌面端：完善赞助内容的导航入口、浅色与深色主题，以及窄窗口下的展示和交互。
- 优化插件端 UI：增加「来自赞助商的广告」菜单，完整说明、附图、邀请码和群号可随时查看。
- 优化广告体验：按设备本地日期每日展示一次完整公告，正文独立滚动，关闭按钮始终可用；支持 Esc 和点击遮罩收起。
- 修复插件在 DSH 设置弹窗内无法展示每日公告的问题；收起公告时保留设置页，并将焦点返回广告菜单。存在其他业务弹窗时仍会等待。
- 公告不要求倒计时、读完正文或点击外链；存储不可用时跳过自动展示，菜单仍可使用。附图内联在安装资源中。
- 同步更新项目交流入口的二维码及中英文安装说明。

## 安装与更新

插件、独立本地服务和 Windows 桌面端版本统一为 2.5.4。

DSH 插件使用 `dsh-our-free-model-2.5.4.tgz`。托管安装更新 profile 中的本地 tarball 路径，并通过宿主解析依赖；同名 npm 包不由本仓库发布。

Windows 桌面端请先从托盘完全退出旧程序，再运行 `Our.Free.Model_2.5.4_x64-setup.exe`。配置、账号和统计数据保留；安装包未经 Authenticode 签名。

下载后按 `SHA256SUMS.txt` 核对文件。发布验收记录随安装产物提供，实际验证范围以该记录为准。

## 回退

完全退出程序后，使用上一版完整安装包或插件 tarball 恢复。保留现有用户数据；托管插件需同步恢复对应依赖路径。
