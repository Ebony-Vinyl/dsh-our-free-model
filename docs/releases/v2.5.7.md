# Our Free Model 2.5.7

## 插件更新

本版本发布 DSH 插件，基于已合入 main 的 PR #481，并包含自 2.5.6 后的主线修正：

- CodeArts 使用独立签名传输，避免其他插件改写全局 fetch 破坏签名；保留代理、超时和取消，积分与签到绑定所属插件实例出口。
- 识别字符串和数字形式的 CodeArts 4004，最多去掉 benefit 请求头并重新签名重试一次。
- 托管安装禁用不适用的插件内升级与热重载操作，并提示通过原安装方式更新。
- 模型手动测速必须收到非空正文且正常结束才判成功；后台总预算为 300 秒，前端等待为 330 秒。
- 保存成功和失败的测速结果；取消不覆盖旧结果，旧探测不能覆盖新实测；区分“清单已收录”“实测可用”和“实测失败”。
- 已移除低性能模式，保留正常动画、主题切换以及免费模型和 EAC 页面赞助卡片。
- 保留主线更新的北辰 API PNG Logo，并修正多模态请求中被上游夸大的用量统计。

独立服务和桌面壳版本保持不变，本次不发布新的 Windows 桌面安装包。标签触发的 macOS 社区构建由现有 CI 单独处理。

## 安装

插件包为 `dsh-our-free-model-2.5.7.tgz`。托管安装请更新 profile 中的可信 tarball 路径，再由宿主重新解析依赖；自行安装按现有插件更新流程操作。

无需迁移用户配置、账号或统计数据。手动测速结果单独保存，不修改原有探测记录结构。

## 验证边界

CodeArts 的签名、代理、取消和多实例隔离经过本地测试；真实 CodeArts 账号在线调用未验证。测试结果不代表上游账号配额或地区准入已解除。

## 回退

回退到 `2.5.6` 的可信插件 tarball，并按宿主安装流程重新解析。用户配置、账号及统计数据保留。
