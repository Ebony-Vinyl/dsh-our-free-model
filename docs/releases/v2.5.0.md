# Our Free Model 2.5.0

## 本次更新

- **修复免费车道全线 403。** 上游在 2026-10-17 给会话 id 追加了**编码校验**，不再只看
  `ses_` 形状：十二位十六进制必须是官方客户端的**降序时间戳**
  （`~(毫秒 << 12 | 计数器)`，计数器 1–63，低十二位落在 `0xfc0–0xfff`）。升序写法
  （`毫秒 << 12`）或任何哈希摘要，即使 `ses_` 形状完全正确，也一律 `403 FreeTierError`。
  - 插件现在按编码校验会话 id：新增 `SESSION_DESCENDING_RE` 与 `isCanonicalSession()`；
  - 调用方传来的**非降序**会话 id 不再原样透传，而是确定性地重编码成合规形状
    （`canonicalizeSession()`，同一段对话仍对应同一个上游会话）。
  - 实测（同一出口 IP、同一时刻）：原始升序 id → 403，重编码后 → 200，新铸造 id → 200。
  - `scripts/free-lane-wire-test.mjs` 的会话一节改为断言真实的编码窗口，并新增「升序
    id 会被重编码」的检查。
- **推荐项目页新增第三个项目：EAC-design-world**（`Ebony-Vinyl/EAC-design-world`）。它是
  DeepSeek Harness 的本地视频制作与设计插件——多轨剪辑、模板与设计体系、原生预览画布、
  真实文件导出，全流程在本机完成。Star / Fork / 最近提交数同样实时取自 GitHub。
  推荐项目公告同步点名这三个仓库，页面上渲染什么、公告里就写什么。
- 插件、独立本地服务和 Windows 桌面壳统一升级到 2.5.0。

## 服务端（EAC 免费车道，非插件内容）

EAC 渠道的 `deepseek-v4.1-flash-free` 与 `glm-5.3-flash-free` 已改走服务器侧的
OpenCode 匿名车道网关，出口经**免费代理池**轮换，单 IP 限流不再影响可用性。这一部分
不随插件分发，此处仅作说明。

## 升级与重启

### DSH 插件

在设置 → 插件升级中检查并安装 2.5.0。升级前结束正在生成的请求；安装完成后完全退出
DSH desktop（包括托盘）并重新启动，再确认版本号与免费模型目录。

### 独立本地服务

先停止旧服务并备份程序目录和数据目录，再替换程序文件。使用原来的数据目录启动新版，
通过启动时输出的管理链接登录，确认页面显示 2.5.0。不要同时运行两个实例共用一个数据目录。

### Windows 桌面应用

从托盘菜单选择“退出”后安装新版完整安装包（`Our.Free.Model_2.5.0_x64-setup.exe`），
再重新打开应用。不要只复制可执行文件；安装包包含独立服务和运行时资源。

### macOS 桌面应用

本次未构建 macOS 安装包（构建机为 Windows）。macOS ARM64 用户请继续使用 v2.3.0 的 DMG，
或直接使用独立本地服务 CLI；本版的免费车道修复同样适用于独立服务。

## 数据与回退

升级保留现有配置、账号和统计数据。会话映射文件 `session-map.json` 里可能存有旧版本写入
的非降序 id：新版本读到时不会直接使用，而是重新编码（编码由对话种子确定，因此仍稳定）。
回退到 2.4.0 不影响用户数据；旧版本在编码校验生效后会重新遇到 403，属预期。
