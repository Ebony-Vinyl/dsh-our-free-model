# Our Free Model 2.5.2

本版汇总本地 issue 审计与已审核 PR 的修复，提供 DSH 插件预构建 tarball 和 Windows x64 完整安装包。

## 修复

- 升级检查在 GitHub API 限流时，依次尝试 git refs 和 Atom 解析固定提交；增加 gcore 清单镜像。清单签名、每文件大小和 SHA-256 校验继续强制执行。
- 修复宿主隐藏模块缓存时升级仍加载旧代码的问题，并保留启动失败后的回滚诊断。回滚只读文件后恢复原权限。
- 修复公告回退源条目减少、恢复或重启后反复通知同一条公告的问题。
- 桌面端账号登录预留浏览器窗口，并在需要时调用宿主打开系统浏览器；修复连接替换、卸载与慢状态请求的竞态。ZCode 可选择 bigmodel.cn 或 z.ai。
- Gemini、MiniMax 保留消息携带的 system 提示词；过滤多个适配器中的空白历史和空白回复，保留工具结果图片与工具调用配对。
- Raccoon、Loomy 对明确额度不足进行有界账号轮换；不在已有输出后重放，不绕过永久积分锁。
- 聚合渠道向上游发送真实模型 ID；中文和混合名称链路保存后可继续使用；链路编辑器显示上下文、输出和视觉能力交集。
- 三种转发协议保留上游错误分类、HTTP 状态和重试提示；SSE 在终止标记停止读取，混合 JSON/SSE 错误不再丢失。
- 修复转发端口冲突后改写期望端口、RTK 误吞缩进源码等问题。

## 功能

- 插件和独立服务支持隐藏单个模型、匿名与 Kilo 整组模型或 EAC 整组模型；隐藏不影响通过已保存 ID 发起历史会话请求。
- 独立服务新增 `--lan`、`--no-lan`、`--lan-port`，提供独立密钥的 LAN 推理中继；管理页面仍仅限本机。
- DSH Tauri 的内核 profile 可被 EAC 宿主识别。
- 新增 LAN 默认回归，修复依赖锁文件，使干净环境可执行 `npm ci --ignore-scripts`。

## 安装

DSH 插件：下载本 Release 的 `dsh-our-free-model-2.5.2.tgz`，按 README 的本地 tarball 流程安装。包管理器拥有安装目录时使用 `distribution: managed`，更新 tarball 路径后通过宿主重新解析依赖，避免重启后恢复旧锁文件版本。本仓库不向同名 npm 包发布。

Windows 桌面版：先退出托盘中的旧程序，再运行 `Our.Free.Model_2.5.2_x64-setup.exe`。保留原数据目录，配置、账号和统计数据不随程序替换而删除。

`SHA256SUMS.txt` 提供两个产物的校验值。Windows 安装包没有 Authenticode 签名；插件升级清单使用既有 Ed25519 发布密钥签名。

## 可用性说明

- 匿名渠道仍可能被上游返回 `403 / LANE_LOCKED`；本版不声称恢复上游准入。授权、地区、配额、证书和上游服务状态依然影响真实推理。
- EAC 连续 60 秒没有正文、思考或工具进展时返回 `NO_PROGRESS`，不自动重试；仅有心跳或用量帧不会延长等待。长时间静默计算也受此限制。
- 自动化验证包括隔离上游；账号渠道没有逐家使用真实账号完成推理验收。
- 本 Release 不提供未经实机验证的 macOS/Linux 安装包；macOS 支持 PR #421 不属于本次已整合改动。
